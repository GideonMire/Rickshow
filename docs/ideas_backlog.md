Virtual Fare Adjustment Coins (“Ricks”)
Problem Observed

When a shared rickshaw fare does not split evenly:

Exact cash amounts are awkward

Online transfers are easier

Social friction increases when someone pays more

Example:

Total fare: ₹60

Host pays ₹15

Remaining split unevenly (₹22.5 / ₹22.5)

One person pays more in cash, other compensates digitally

Idea Summary

Introduce a virtual coin / credit system (working name: Ricks):

Used only between passengers

No real-money storage

Only compensates uneven splits

Transfers happen after the ride

Example flow:

P2 pays ₹20

P3 pays ₹25

P2 transfers 5 Ricks to P3

Important Notes

This is not a wallet

No top-ups or withdrawals

No cash storage

No payments to drivers

Only peer compensation
